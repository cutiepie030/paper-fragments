# PAPER FRAGMENTS · 碎纸诗

> *Make poetry out of little things.*
> 「把偶然遇见的词，拼成只属于你的诗。」

一个轻量、精致、具有文学美感的**随机拼贴诗互动网页**。把从旧书、杂志、杂志标题上「剪」下来的词，自由拖到一张纸上，拼成只属于你的诗。

## ✨ 核心玩法

- **随机文字素材**：打开即生成 12–18 个文学感词卡，按类型加权平衡抽取（名词 / 动词 / 形容词 / 时间 / 连接 / 意象 / 情感 / 英文），词库 250+ 原创词条。
- **拖拽拼贴**：鼠标 + 手机触摸统一支持（Pointer Events）。从左侧素材区拖到中央纸张，画布内继续自由移动、旋转、改字。
- **纸片编辑**：点击选中 → 浮动文具菜单，改字色 / 底色 / 字体 / 字号 / 旋转 / 文字 / 删除。内置 5 种纸片风格。
- **纸张背景**：OLD PAPER / SOFT PINK / BLUE DIARY / NEWSPAPER 四种，切换不改变已有文字位置。
- **贴纸 & 胶带**：10 个原创 SVG 贴纸 + 4 款和纸胶带，自由添加、移动、缩放、删除。
- **撤销 / 重做**：真实状态历史栈（最多 60 步）。
- **保存**：localStorage 自动存档，刷新可「继续上次创作」。
- **导出**：一键生成 **1080×1440** 高清 PNG，仅含作品本身与底部极简署名，不含任何操作 UI。

## 🛠 技术栈

纯前端，**零构建、零后台、零第三方付费 API**：

- `index.html` — 页面结构（桌面三栏 / 手机堆叠自适应）
- `styles.css` — 复古纸张 × 韩系独立志视觉，含纸张颗粒底纹
- `app.js` — 拖拽、编辑、撤销、保存、Canvas 导出
- `words.js` — 原创中文 / 英文词库
- `stickers.js` — 原创 SVG 贴纸与和纸胶带

内部使用 **1080×1440 设计坐标系**，元素以相对坐标存储，桌面 / 手机 / 导出三端布局一致。

## 🚀 本地运行

直接双击 `index.html` 即可。或起一个静态服务器：

```bash
python3 -m http.server 8000
# 浏览器打开 http://localhost:8000
```

## ☁️ 部署

纯静态站点，可直接托管到 **GitHub Pages / Vercel / Netlify / 腾讯云 CloudBase**。
GitHub Pages：仓库根目录 + `main` 分支即可，无需构建步骤。
